# C3 Collaboration Context

## Purpose

This document defines the C3 Collaboration bounded context of Ankhora.

C3 enables secure collaboration between trusted participants.

C3 answers:

> "How can people and organizations collaborate around protected information?"

---

# Mission

C3 provides the collaboration layer of Ankhora.

It manages:

- collaborative spaces
- communication structures
- participant relationships
- trust groups
- collaboration lifecycle

C3 enables cooperation without taking ownership of protected data.

---

# Core Principle

C3 is not a storage system.

C3 is not the owner of user data.

C3 coordinates collaboration around protected assets.

The ownership model remains:

```

Vault

owns information

```
    |
```

C3

coordinates collaboration

```

# Forbidden Patterns

## C3 Owning Assets

Wrong:

```

C3 Database

contains user documents

```

---

## C3 Replacing Vault

Wrong:

```

C3 encrypts everything itself

```

---

## Global Collaboration Permissions

Wrong:

```

One global permission system controls all contexts

```

---

## Direct User Identity Logic

Wrong:

```

C3 creates users

```

---

# AI Implementation Rules

When implementing C3 features, AI should ask:

1. Is this collaboration logic?
2. Does Vault own this data?
3. Does Identity own this identity?
4. Is this a domain event?
5. Should this be realtime?
6. Is permission ownership clear?
7. Does this cross a federation boundary?
